═══════════════════════════════════════════════════════════════════════════════
                              STEP-BY-STEP SETUP
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Navigate to Project Root
────────────────────────────────────────────────────────────────────────────

Open PowerShell and navigate to the project root:

  cd d:\Project\MORPHEUS

You should see this prompt:
  PS D:\Project\MORPHEUS>


STEP 2: Verify Python Installation
────────────────────────────────────────────────────────────────────────────

Check that Python is installed:

  python --version

You should see something like:
  Python 3.12.0

If not, install Python 3.7+ from python.org


STEP 3: Create Virtual Environment (If Not Already Created)
────────────────────────────────────────────────────────────────────────────

  python -m venv .venv

This creates a virtual environment in the .venv folder.


STEP 4: Activate Virtual Environment
────────────────────────────────────────────────────────────────────────────

  .\.venv\Scripts\activate

After activation, your prompt should show (.venv):

  (.venv) PS D:\Project\MORPHEUS>


STEP 5: Install Dependencies
────────────────────────────────────────────────────────────────────────────

  pip install -r requirements.txt

This installs the pefile package required for PE analysis.


═══════════════════════════════════════════════════════════════════════════════
                         HOW TO RUN THE PROJECT
═══════════════════════════════════════════════════════════════════════════════

Always from: d:\Project\MORPHEUS (NOT from tests/ folder!)


OPTION 1: RUN INDIVIDUAL TESTS
────────────────────────────────────────────────────────────────────────────

Test Stage 1 (Static Analyzer):
  python tests/test_static.py

Test Stage 2 (Behavior Intelligence):
  python tests/test_behavior.py

Test Stage 3 (Detection Engineering):
  python tests/test_detection.py


OPTION 2: RUN FULL SYSTEM VERIFICATION
────────────────────────────────────────────────────────────────────────────

Verify entire system:
  python setup_and_verify.py

This runs all stages and generates YARA rules.


OPTION 3: ANALYZE A FILE
────────────────────────────────────────────────────────────────────────────

Put your malware sample in: d:\Project\MORPHEUS\data\uploads\

Then run:
  python

Then in Python:

    from core.analyzer import analyze_file
    from core.risk_engine import calculate_risk_score
    
    # Analyze the file
    analysis = analyze_file("data/uploads/sample.exe")
    
    # Calculate risk
    risk = calculate_risk_score(analysis)
    
    print(f"Risk Score: {risk['risk_score']}/100")
    print(f"Risk Level: {risk['risk_level']}")


OPTION 4: GENERATE YARA RULE
────────────────────────────────────────────────────────────────────────────

In Python:

    from core.analyzer import analyze_file
    from core.yara_generator import generate_yara_rule, export_rule_to_file
    
    # Analyze file
    analysis = analyze_file("data/uploads/sample.exe")
    
    # Generate YARA rule
    rule = generate_yara_rule(analysis, rule_name="my_malware")
    
    # Export to file
    export_rule_to_file(rule, "rules/my_malware.yar")
    
    print("YARA rule saved to: rules/my_malware.yar")


═══════════════════════════════════════════════════════════════════════════════
                           COMMON MISTAKES
═══════════════════════════════════════════════════════════════════════════════

❌ MISTAKE 1: Running from tests folder
────────────────────────────────────────────────────────────────────────────

Wrong:
  PS D:\Project\MORPHEUS\tests> python test_static.py
  Error: ModuleNotFoundError: No module named 'core'

Right:
  PS D:\Project\MORPHEUS> python tests/test_static.py
  (works correctly)

REASON: The test files import from 'core' which is at the parent directory level.


❌ MISTAKE 2: Double path in command
────────────────────────────────────────────────────────────────────────────

Wrong:
  python tests/tests/test_static.py
  Error: No such file or directory

Right:
  python tests/test_static.py

REASON: Don't repeat the folder name in the path.


❌ MISTAKE 3: Not activating virtual environment
────────────────────────────────────────────────────────────────────────────

Wrong:
  PS D:\Project\MORPHEUS> python test_static.py
  Error: ModuleNotFoundError

Right:
  PS D:\Project\MORPHEUS> .\.venv\Scripts\activate
  (.venv) PS D:\Project\MORPHEUS> python tests/test_static.py

REASON: The virtual environment contains installed packages (pefile, etc).
